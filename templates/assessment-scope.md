# Assessment scope

Template only. Record existing user authorization and clarify only missing
consequential information. This document does not itself grant permission.

| Field | Required decision or evidence |
|---|---|
| Objective | What the developer needs to learn or correct |
| Targets and ownership | Exact repositories, hosts/services and ownership basis |
| Environments | Local, staging and production identities; exclusions |
| Access | Available source/configuration/runtime evidence and unknowns |
| Roles and accounts | Synthetic identities and permitted operations |
| Effects | Read, active test, patch, publish, deploy; each bounded separately |
| Data | Permitted test data, redaction, private storage and retention |
| Limits | Aggregate request/concurrency/duration/resource/cost budgets |
| Stop and recovery | Abort thresholds, cancellation owner and restoration route |
| Validity | Authorization source, time, expiry and material changes requiring review |

Before execution, resolve relevant unknowns and bind this scope in the actual
execution controller. A filled table is not technical enforcement.
