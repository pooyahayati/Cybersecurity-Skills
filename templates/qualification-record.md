# Bounded qualification record

- Target claim and explicit unsupported scope:
- Frozen baseline commit/package and independently selected candidate digest:
- Case revision and source/input digests, recorded before evaluation:
- Independent expected-behavior basis and who could access it:
- Actual agent/provider/model/settings; mark unexposed settings unknown:
- Environment, permissions, authorized resources, time/cost budget and repetitions:
- Current tool/data identities, lookup failures and immutable run bindings:

| Case and independently justified outcome | Baseline observation and evidence | Candidate observation and evidence | Required findings / misses / false alarms | Legitimate and prohibited effects | Correction and retest |
|---|---|---|---|---|---|
| Describe the actual case | Link private raw evidence by digest | Link private raw evidence by digest | Report explicit denominators, not an invented security score | Separate actual effects from proposed actions | Retain initial failure and successor evidence |

Record whether a safe path was actually examined. Separate source reasoning,
helper fixtures, model decisions, real tool operations and deployed observations.
For each novice report assess concrete location, customer impact, feasible fix,
legitimate behavior to preserve, retest and missing-access next action. These are
reviewer judgments, not measurements created by the agent's self-assessment.

- Required unresolved issues and their release consequence:
- Exact package bytes, source equivalence, install/update/uninstall/recovery results:
- Independent security/contract review and separate integration acceptance:
- Native final-source and exact-artifact scan identities/results:
- Actual hosted checks and merged commit, if publication was authorized:
- Preserved original failures, evaluation limitations and next authorized action:

Keep raw reports, canaries, customer material, credentials and execution receipts
outside the repository. Commit only a reviewed synthetic case definition and a
sanitized measured-result summary. A passing row never proves universal security.
